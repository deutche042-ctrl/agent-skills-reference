# Company Registries

## Use Cases
- Retrieve a company's registration number, jurisdiction, status, and registered address
- Obtain authoritative source links for verification

## Common Methods
- API first: use open interfaces to search company records
- GUI fallback: verify page fields or download PDF attachments

## GUI Guidance
- Enter the company name on the official website and select the matching record
- Extract the registration number, jurisdiction, status, and address, and record the source link

## API and Programmatic Access
- OpenCorporates search API
- Official national or regional registry APIs, following each site's documentation

## Authoritative Sources and URLs
- OpenCorporates: https://opencorporates.com / API: https://api.opencorporates.com
- UK Companies House: https://www.gov.uk/government/organisations/companies-house
- U.S. state registries: search the relevant official state website (for example, California: https://bizfileonline.sos.ca.gov/)

## Example Task
- Look up a company's registration details and provide the source link and key fields
