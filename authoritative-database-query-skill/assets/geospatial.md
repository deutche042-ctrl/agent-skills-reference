# Geospatial Data

## Use Cases
- Retrieve coordinates, map features, and public geospatial datasets
- Record feature IDs and source links

## Common Methods
- API first: use OSM, GeoNames, Nominatim, or Overpass interfaces
- GUI fallback: download datasets or browse pages for complex features

## GUI Guidance
- Search for a place or feature on a mapping website and open its details page
- Record coordinates and feature IDs, and export as needed
- Select dataset downloads by scale and theme

## API and Programmatic Access
- Overpass API
- Nominatim search API
- GeoNames search API

## Authoritative Sources and URLs
- OpenStreetMap: https://www.openstreetmap.org
- Overpass: https://overpass-turbo.eu / API: https://overpass-api.de/api/interpreter
- Nominatim: https://nominatim.openstreetmap.org
- GeoNames: https://www.geonames.org / API: http://api.geonames.org
- Natural Earth: https://www.naturalearthdata.com

- Retrieve a landmark's coordinates and feature ID, and provide the source link
