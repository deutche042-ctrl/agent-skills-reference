# Knowledge Graphs and General Knowledge

## Use Cases
- Retrieve structured entity attributes and general knowledge
- Obtain verifiable citations and sources

## Common Methods
- API/SPARQL first: use query endpoints to obtain structured results
- GUI fallback: browse entity pages and trace references back to their sources

## GUI Guidance
- Search for the entity, open its page, and record its entity ID and key attributes
- Follow references back to the original authoritative sources

## API and Programmatic Access
- SPARQL query endpoint
- Project-provided REST APIs

## Authoritative Sources and URLs
- Wikidata: https://www.wikidata.org / SPARQL: https://query.wikidata.org/sparql
- Wikipedia: https://www.wikipedia.org / API: https://en.wikipedia.org/w/api.php

## Example Task
- Find a company's CEO, founding date, and headquarters, and provide the entity ID and sources
