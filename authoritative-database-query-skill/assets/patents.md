# Patents

## Use Cases
- Retrieve patent application and grant data, inventors, and assignees
- Obtain application numbers, filing dates, and source links

## Common Methods
- API first: use official or open interfaces to search by keyword and assignee
- GUI fallback: use when API access is limited or page-level details are needed

## GUI Guidance
- Search the official website by technical term or assignee and open the record page
- Record the application number, filing date, inventors, and link
- Cross-check important records against multiple sources

## API and Programmatic Access
- USPTO PatentsView
- EPO OPS (developer registration required)
- Some platforms require a token or paid access; follow the site's instructions

## Authoritative Sources and URLs
- USPTO PatentsView: https://patentsview.org / API: https://api.patentsview.org
- EPO OPS: https://www.epo.org / Developer portal: https://developer.epo.org
- Lens: https://www.lens.org / API: https://api.lens.org (token required)

## Example Task
- Search for patents related to CRISPR-Cas9 and return application numbers and source links
