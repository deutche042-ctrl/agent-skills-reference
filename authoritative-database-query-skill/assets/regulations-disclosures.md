# Regulations and Disclosures

## Use Cases
- Search regulations, case law, and official disclosures by public companies
- Obtain official identifiers (such as CELEX numbers) and authoritative source links

## Common Methods
- API first: retrieve metadata and structured records
- GUI fallback: use for long-form reading, attachment downloads, or content available only on the page

## GUI Guidance
- Search the official website by regulation name or number, then filter by language and year
- Open the legal text page and copy the official citation and link
- For public-company disclosures, search the latest records by company name and document type

## API and Programmatic Access
- EDGAR Open Data (XBRL Company Facts)
- EUR-Lex Webservice

## Authoritative Sources and URLs
- SEC EDGAR: https://www.sec.gov/edgar / Open Data: https://data.sec.gov
- EUR-Lex: https://eur-lex.europa.eu / Webservice: https://eur-lex.europa.eu/oeil-static/api

## Example Tasks
- Find Apple Inc.'s latest annual filing and return a summary of key financials with the official link
- Locate the official GDPR text and provide its CELEX number and source link
