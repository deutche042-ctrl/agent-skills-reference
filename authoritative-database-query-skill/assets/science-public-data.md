# Scientific and Public Data

## Use Cases
- Retrieve chemistry, life-science, and public scientific data
- Obtain authoritative identifiers and source links

## Common Methods
- API first: use official REST APIs to search by identifier or keyword
- GUI fallback: use for page details and download operations

## GUI Guidance
- Record the CID, accession or ID, units, and data description from the record page
- Use filters to narrow by species, year, or category
- Cross-check key conclusions against multiple sources

## API and Programmatic Access
- PubChem PUG REST
- UniProt REST
- NASA and NOAA open-data APIs

## Authoritative Sources and URLs
- PubChem: https://pubchem.ncbi.nlm.nih.gov / PUG REST: https://pubchem.ncbi.nlm.nih.gov/rest/pug
- UniProt: https://www.uniprot.org / REST: https://rest.uniprot.org
- NASA Open Data: https://data.nasa.gov / APIs: https://api.nasa.gov
- NOAA: https://www.noaa.gov / CDO API: https://www.ncdc.noaa.gov/cdo-web/api

- Retrieve water's PubChem CID and IUPAC name and provide the source link
