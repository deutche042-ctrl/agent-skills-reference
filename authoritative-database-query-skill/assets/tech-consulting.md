# Technology Consulting and Industry Reports

## Use Cases
- Conduct industry research and gather market-sizing and trend insights
- Obtain report titles, publication dates, and organization details

## Common Methods
- GUI first: use public summaries and report pages on official websites
- APIs/data interfaces: most organizations do not provide a unified open API; follow each site's instructions

## GUI Guidance
- Enter topic keywords in the site search and filter by year, industry, and region
- Open the report or insights page and record the title, publication date, author or organization, version, and page number
- If content is paywalled, capture the executive summary and cross-check key figures against authoritative data sources

## Example Task
- Find the latest insight report on a topic and return key takeaways and the source link
