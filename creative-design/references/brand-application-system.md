# Brand Application System

## Main Skill Routing Fit

Use this reference for brand applications, key visuals, campaign posters, communication covers, content cards, banners, brochures, leaflets, landing pages, exhibition materials, roll-up banners, store materials, stickers, merchandise, and offline touchpoints.

## Product Skill Boundary

This reference creates brand-applied visuals. It does not automatically create a full VI manual, production-ready print files, or a complete marketing campaign unless the user asks and confirms scope.

## Image Count Strategy

- Single application material: 1 image.
- Several directions for the same material: 2-3 images.
- Multi-material system: first confirm the core asset or key visual, then extend 3-4 priority materials.
- Full campaign or brand system: plan scope before generation.

## General Execution Core

1. Identify the inherited core asset: logo, IP, package, key visual, brand color, or layout system.
2. Identify the target touchpoint: online cover, poster, banner, landing page, brochure, roll-up banner, store graphic, sticker, or merchandise.
3. Use `image_edit` when a core brand asset exists.
4. Keep visible text concise and provided or safely inferred.
5. Translate platform or usage labels into visual density, composition, and reading context in the prompt.

## Core Strategy: Consistency And Diversity

### Consistency Lock

Preserve brand logo, color palette, typography character, key visual motif, IP/product/package identity, and campaign mood.

### Diversity Release

Vary layout, scale, crop, rhythm, background, material, and touchpoint-specific hierarchy.

## Rewrite Strategy

Turn abstract goals into concrete visual direction. For example, "make it more high-end" becomes restrained composition, refined spacing, premium material texture, precise typography hierarchy, and controlled contrast.

## Optional Products

Online communication cover, content card, carousel page, campaign poster, banner, mobile landing page, H5 long page, brochure, leaflet, roll-up banner, exhibition board, store window film, wall sticker, product sticker, tote bag, badge, invitation, coupon, and small print material.

## Online Communication Applications

### Online Structure Rules

Online visuals need strong first-screen hierarchy, fast readability, and platform-appropriate density. Separate headline, supporting message, product/brand visual, CTA or time information, and decorative system.

Do not include fake dates, prices, discounts, QR codes, rankings, or campaign names unless supplied.

### Marketing Reference Reading Strategy

#### General Communication Image Rules

Use a clear focal point, concise copy, brand color anchors, and enough negative space. For platform covers, prioritize click-through and instant topic recognition. For brand campaign posters, prioritize brand mood and message hierarchy.

### Online Landing Page / Campaign Page

Represent the first screen or selected sections, not a complete coded page. Use mobile-first vertical composition for H5/landing pages, with modular sections and clear hierarchy.

### Online Material Prompt Templates

#### Platform Communication Cover

Create a platform-ready brand communication cover using the provided core asset, strong focal composition, concise headline area, brand-color system, high readability, and no fake platform UI.

#### Content Card / Carousel Page

Create a single content card with structured hierarchy, clear topic title, supporting visual elements, consistent brand system, and readable information density.

#### Campaign Poster / Banner

Create a campaign poster or banner based on the core brand asset, with a strong key visual, clear headline area, brand palette, and commercially polished layout.

#### Mobile Landing Page

Create a mobile-first landing-page visual with modular sections, clear hero area, brand asset integration, concise text blocks, and strong conversion hierarchy.

## Material Extension Principles

Derivatives should feel like the same system across sizes and carriers. Preserve the core visual motif and adapt hierarchy to each material instead of stretching the same layout mechanically.

## Genre And Tone Standards

Brand application tone may be premium, youthful, tech, cultural, playful, professional, warm, or editorial. Express tone through composition, type scale, color contrast, materials, and image treatment rather than unsupported brand claims.

## Offline / Physical Applications

Offline visuals must account for viewing distance, carrier material, and production plausibility. Large-format materials need fewer words and stronger contrast. Small print materials need clean margins and legibility.

## Space Sticker / Wallpaper / Window Film Rules

Use repeated motifs, modular graphics, and brand-color anchors. Avoid overcrowding real spatial scenes. For window film, consider transparency and readable negative space.

## Small Print Material Rules

For cards, coupons, invitations, tags, and stickers, keep text short, hierarchy clear, margins generous, and decorative details controlled.

## Event System Rules

Event materials should share one campaign key visual and adapt it to poster, banner, backdrop, badge, signage, and social cover. Do not invent event dates or venue details.

## Brochure / Leaflet Rules

### Brochure / Catalog / Product Manual

Represent selected spreads or a cover concept unless the user asks for multiple pages. Use modular grids, image-text rhythm, clear section titles, and brand consistency.

### Leaflet / Tri-Fold

Show panels, fold logic, cover/back hierarchy, and concise information zones. Do not fill with fake paragraphs.

## Prompt Strategy

Include core asset usage, target material, visible text, hierarchy, layout, color system, material or screen context, and style. For derivatives, explicitly preserve the core asset and describe the adaptation.

## High-Density Application Text Strategy

If much text is required, simplify rather than invent. Use short user-provided titles and representative labels. For dense brochures or long pages, generate selected screens/pages rather than unreadable full content.
