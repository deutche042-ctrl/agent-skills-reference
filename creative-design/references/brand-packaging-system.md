# Packaging System

## Main Skill Routing Fit

Use this reference for packaging, product packages, gift boxes, bottle labels, cans, pouches, cartons, dielines, wrapping paper, seals, hang tags, unboxing visuals, shelf displays, and SKU variants.

## Overview

Packaging work must balance commercial shelf impact, information hierarchy, structural plausibility, production awareness, and brand consistency. If a logo or brand asset exists, use it as the core reference for all packaging derivatives.

### Product Skill Boundary

This reference covers packaging visuals and packaging-related flat layouts. It does not replace engineering-grade dieline production files or legally compliant label copy.

## Use Cases

### Intent Understanding And Product Routing

Route to packaging when the core request is the container, label, box, pouch, wrapping system, SKU packaging family, or packaging mockup. Route to e-commerce when the core request is product sales conversion on a platform.

### Packaging Type Selection

Common types include box, gift box, carton, pouch, sachet, bottle label, can label, jar label, sleeve, wrap, hang tag, seal sticker, insert card, wrapping paper, and shelf-ready display.

## Core Workflow

### Image Count Strategy

- Single package concept or edit: 1 image.
- Multiple packaging directions: 2-3 images with different structure or visual systems.
- Packaging family or SKU variants: create the main package first, then extend variants from it.
- Full packaging system: plan scope before generation.

### General Execution Core

1. Identify product category, package type, brand asset, required text, and usage.
2. Decide whether the output is flat artwork, mockup, display scene, dieline concept, or packaging family.
3. Use `image_gen` for first concepts without a reference.
4. Use `image_edit` for all derivatives based on a logo, package, product, or brand system.
5. Keep claims, ingredients, certifications, and regulatory copy only when provided.

### Core Strategy: Consistency And Diversity

#### Consistency Lock

Preserve brand logo, product name, color system, package structure, key graphic motif, and SKU family logic.

#### Diversity Release

Vary SKU color bands, flavor markers, secondary illustrations, layout rhythm, or material effects without changing the core identity.

#### Main Package To Derivative Assets

After the main package is approved, use it for variant SKUs, stickers, hang tags, wrapping paper, shelf displays, and e-commerce images.

### Rewrite Strategy

Translate vague requests such as "make it premium" into concrete visual dimensions: restrained palette, tactile paper texture, precise typography hierarchy, generous negative space, foil or emboss-like accents, and product/category cues.

### Packaging Scheme Chain

If the user asks for logo + packaging + poster, first establish the logo, then packaging, then application/poster. If an existing logo is uploaded, treat it as the core brand asset.

## Output Forms

### Size And Ratio Defaults

- Single front-facing package: 3:4 or 4:5.
- Bottle/can/pouch hero mockup: 4:5.
- Dieline concept or flat spread: 16:9 or 3:2.
- Wrapping paper or repeat pattern: 1:1.
- Shelf display: 16:9.

### Flat Packaging Product Modes

- Front label layout.
- Box face layout.
- Concept dieline / unfolded package.
- Wrapping paper repeat tile.
- Seal, sticker, hang tag sheet.
- Insert card or instruction card.

### Optional Products

Mockup, unboxing scene, shelf display, SKU family, gift set, limited-edition variant, and brand touchpoint extension.

## Design Standards

### Structure And Information Architecture

Prioritize brand/logo, product name, category, flavor/variant, key benefit, net content, and secondary details. Use clear visual hierarchy and leave enough breathing room.

### Print And Production Boundaries

Do not pretend to deliver print-ready dielines, bleed, barcode validity, certification compliance, or exact material specifications unless the user provides them. Represent them visually as concepts.

### Flat Artwork Rules

For flat packaging layouts, avoid perspective scenes, hands, shelves, or lifestyle backgrounds unless requested. Keep edges, panels, folds, and alignment plausible.

### Category Guidance

Food, beauty, beverage, electronics, gifts, and cultural products each require different material cues, information density, and trust signals. Do not invent health or efficacy claims.

### Packaging Extension Methods

Extend via color system, pattern, illustration set, label architecture, icon style, material finish, or SKU coding.

### Pattern And Wrapping Paper System

Repeat patterns should be tileable, not poster-like. Use a clear motif library, consistent spacing, and limited colors.

### Prompt Strategy

Include package type, product category, brand asset usage, visible text, information hierarchy, material, color system, composition, and whether the image is flat artwork or mockup.

### Flat Product Prompt Templates

#### Concept Dieline / Flat Spread

Create a flat unfolded packaging concept with clear panels, fold lines, brand area, product name area, structured information hierarchy, and print-design style. Keep it conceptual, clean, and production-aware.

#### Pattern / Repeat Tile

Create a seamless repeat pattern using brand motifs, controlled spacing, limited palette, and tileable structure, suitable for wrapping paper or inner lining.

#### Wrapping Paper Flat Design

Create a flat wrapping paper design with repeated brand motifs, balanced density, and a premium commercial packaging feel.

#### Greeting Card / Insert / Instruction Card

Create a compact flat card layout with concise text, brand visual language, clear hierarchy, and generous margins.

#### Seal / Sticker / Hang Tag Sheet

Create a sheet of coordinated packaging accessories, preserving the brand system, with simple shapes, clear icons or motifs, and no fake legal copy.

### Packaging QA

Check package type, brand consistency, hierarchy, text validity, structural plausibility, ratio, and whether any unsupported claims or fake regulatory elements were invented.
