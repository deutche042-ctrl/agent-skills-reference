# US Visa Application Guide

Form structure, field descriptions, and support-material specifications for Chinese citizens applying for a US non-immigrant visa (B1/B2 tourism/business).

---

## 1. DS-160 Online Form Structure

The DS-160 is the unified online application form for all US non-immigrant visas, completed online through CEAC (Consular Electronic Application Center). There is **no paper version**.

### Form Sections and Fields

#### Section 1: Personal Information

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 姓 | Surname / Family Name | Match passport, all uppercase |
| 名 | Given Names | Match passport, all uppercase |
| 曾用名 | Have you ever used other names? | Fill in if yes; select No if none |
| 电码 | Telecode Name | Chinese-name telecode (four digits) |
| 性别 | Sex | Male / Female |
| 婚姻状况 | Marital Status | Single / Married / Divorced / Widowed / Separated |
| 出生日期 | Date of Birth | **MM/DD/YYYY** (e.g., 01/15/1990) |
| 出生城市 | City of Birth | e.g., BEIJING |
| 出生省份 | State/Province of Birth | e.g., BEIJING |
| 出生国家 | Country of Birth | CHINA |
| 国籍 | Nationality | CHINA |

#### Section 2: Travel Information

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 访美目的 | Purpose of Trip | TOURISM/BUSINESS, etc. |
| 具体签证类别 | Specific Visa Class | B1 (business) / B2 (tourism) / B1/B2 |
| 预计到达日期 | Intended Date of Arrival | MM/DD/YYYY |
| 预计停留时间 | Intended Length of Stay | Days/weeks/months |
| 在美住址 | Address Where You Will Stay | Hotel or host's address |
| 旅费支付人 | Who is Paying for Your Trip | Self / Other Person / Company |

#### Section 3: Travel Companions

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 是否有同行人 | Are other persons traveling with you? | Yes / No |
| 同行人姓名 | Companion Name | Full name |
| 同行人关系 | Relationship | Spouse / Child / Friend, etc. |

#### Section 4: Previous US Travel

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 是否去过美国 | Have you ever been in the US? | Yes / No |
| 上次赴美日期 | Date of Last Arrival | MM/DD/YYYY |
| 停留时间 | Length of Stay | Days/weeks/months |
| 是否持有美国签证 | Have you ever been issued a US visa? | Yes / No |
| 是否被拒签 | Have you ever been refused a US visa? | Yes / No; if refused, answer truthfully |

#### Section 5: US Contact Information

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|

| 联系人电话 | Phone Number | Including area code |
| 联系人邮箱 | Email | |

#### Section 6: Family Information

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 父亲姓名 | Father's Full Name | |
| 父亲出生日期 | Father's Date of Birth | MM/DD/YYYY |
| 母亲姓名 | Mother's Full Name | |
| 母亲出生日期 | Mother's Date of Birth | MM/DD/YYYY |
| 是否有直系亲属在美 | Do you have any immediate relatives in the US? | Yes / No |

#### Section 7: Work / Education / Training

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 当前职业 | Primary Occupation | e.g., SOFTWARE ENGINEER |
| 雇主名称 | Employer or School Name | Full company/school name |
| 雇主地址 | Employer Address | Full address |
| 雇主电话 | Employer Phone | Including +86 |
| 职位 | Job Title | |
| 月收入 | Monthly Salary | e.g., CNY 30,000 |
| 工作起始日期 | Start Date | MM/DD/YYYY |
| 工作职责描述 | Briefly Describe Your Duties | Brief description in English |

#### Section 8: Security and Background

Covers questions about criminal records, terrorist organizations, infectious diseases, drugs, human trafficking, etc.; answer Yes / No truthfully.

#### Section 9: Social Media (mandatory since June 2025)

| Field (Chinese) | English Label | Instructions |
|------|---------|---------|
| 社交媒体平台 | Social Media Platform | Select the platform name |
| 用户名 | Social Media Identifier | All accounts used in the past 5 years |

## 2. Photo Requirements

| Item | Requirement |
|------|------|
| Size | 51mm × 51mm (2 inches × 2 inches) |
| Background | Pure white |
| Taken within | The last 6 months |
| Format (electronic) | JPEG, 600×600 to 1200×1200 pixels |
| File size | No more than 240KB |
| Expression | Natural expression, both eyes open |

---

## 3. Date and Format Conventions

| Item | US Format |
|------|---------|
| Date | **MM/DD/YYYY** (month/day/year) |
| Name | All uppercase, Surname and Given Names filled in separately |
| Phone | +86-138-0000-0000 |
| Currency | USD (US dollar), e.g., USD 5,000.00 |
| Address | English, from smallest to largest (house number → street → city → province → country) |

## 5. Important Notes

1. **DS-160 is completed entirely online**; blank forms cannot be downloaded. After completion, print the confirmation page (with barcode) to bring to the visa interview
2. **Name telecode** (Telecode): the Chinese name must be converted into a four-digit telecode, which can be looked up online
3. **Social media information** is mandatory (since June 2025); you must provide usernames from all platforms used in the past 5 years
4. US visas emphasize **ties to home country**; materials should highlight family, property, and employment ties in China
5. Bring to the visa interview: the DS-160 confirmation page, passport, photo, appointment confirmation letter, and all support materials
6. Fee: non-immigrant visa application fee $185 (B1/B2), may be adjusted in 2026
