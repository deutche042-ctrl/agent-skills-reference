# Lite Edit Mode

Preserve the source file and write the result to a new path unless the user explicitly authorizes overwrite.

Before editing, record the source page count, aspect ratio, notes count, fonts, hyperlinks, charts, tables, media, and whether important objects are editable. Run the static validator on the source. Render the source only when the request depends on pixel-level or brand fidelity.

Classify the requested change as content edit, visual polish, restructure, reference reconstruction, or migration. Preserve wording, facts, page order, master, notes, links, media, animations, and editable objects unless the requested mode authorizes changes.

After editing, compare page count, ratio, notes, and required assets with the source. Run Lite QA on the new file. Disclose any round-trip limitation or intentional preservation exception.
